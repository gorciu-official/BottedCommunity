# BottedCommunity

I didn't know how to call this, but basically if you write a good system prompt, then you may get self-bots that write in your Discord server, making it active or something.

*Should be* platform-independent, meaning that you can add new AI or chat backends very quickly.

Currently it wasn't deployed by me to any Discord server, except for my testing one, but I am planning on testing this slop on multiple Discord servers once it gets good enough.

See `src/config.ts` for configuration schema.
